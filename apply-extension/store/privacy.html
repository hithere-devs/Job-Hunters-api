Huntly Apply privacy policy

Last updated 17 September 2026.

Huntly Apply is a Chrome extension used with the Huntly job-application runner. It reads the current tab’s application form so Huntly can fill fields the user already answered in Huntly. It does not create an account, show ads, or sell data.

What it accesses

On pages where it is allowed to run, the extension reads form labels, field types, options, and current values, then writes values Huntly supplies. Resume files are attached by the Huntly runner, not uploaded by this extension to a third party.

What it collects and transmits

The extension has no analytics, crash reporter, or its own backend. It does not send form contents to Google, to Huntly’s servers, or to anyone else from inside the extension. Huntly’s separate apply runner (running on the user’s machine or VM) may read the same page through Chrome automation; that runner is covered by Huntly’s product terms, not by this extension listing.

Host access

Job applications live on employer and ATS domains (Greenhouse, Lever, Ashby, SmartRecruiters, Workable, and company career sites). The extension requests broad site access so it can fill those forms after a listing hops onto the real apply page. It does not use that access to scrape unrelated sites.

User control

Uninstalling the extension removes it. Huntly’s runner can also load an unpacked copy for automation; that copy is the same code and follows this policy.
